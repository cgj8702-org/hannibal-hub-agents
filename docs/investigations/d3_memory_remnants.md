## 1. WHY It Exists in the First Place

### 1.1 The Tiered Prompting Architecture (PR #316)
In commit [`99f3bb4`](file:///home/carly/coding/synced-repos-cgj8702/hannibal/hannibal-hub-agents/src/webhook_agent/core/prompts.py#L173-L193) (PR #316, *"refactor(prompts): implement 3-tier prompt architecture and gemini context caching (#316)"*), the prompt builder was restructured into a 3-tier hierarchy designed to maximize Gemini context caching:
1. **Tier 1 (Static System Instructions):** Stable across all executions and repositories. Cached globally for models supporting prefix caching (min 4,096 tokens).
2. **Tier 2 (Repository Profile & Heuristics):** Semi-stable context specific to a target repository, generated by [`build_repo_profile_context()`](file:///home/carly/coding/synced-repos-cgj8702/hannibal/hannibal-hub-agents/src/webhook_agent/core/prompts.py#L173-L193).
3. **Tier 3 (Dynamic Turn Content):** Ephemeral per-PR turn data (diffs, AST symbol reports, test impact, commit messages).

### 1.2 The Memory Bank Heuristics Parameter
When authoring Tier 2 in `src/webhook_agent/core/prompts.py:173-193`, the author designed `build_repo_profile_context` to accept:
```python
def build_repo_profile_context(
    repo_name: str,
    primary_stack: str = "Python 3.13, uv, Google ADK, PyGithub, Pub/Sub, Firestore",
    memory_bank_heuristics: list[str] | None = None,
) -> str:
```
The intention was that an agentic "Memory Bank" or the ADK `MemoryService` would extract repository-specific architectural rules and past review findings across PRs, feeding them into `memory_bank_heuristics` so Tier 2 would render:
```markdown
### Repository Review Heuristics (Memory Bank)
- Always check AST diff chunk bounds
- Verify CI status before review
```

### 1.3 Why It Became a Dead Parameter
1. **The Memory Service Had Zero Readers:**
   As established in `docs/plans/repo_reclamation.md` item `B5`, the memory subsystem (`src/webhook_agent/core/memory_service.py`) was completely abandoned. While `add_session_to_memory()` existed, no memory search tool was registered on the agent, and no code path in `src/` ever retrieved memories.
2. **The Sole Caller Passes Repo Name Only:**
   The only production call site for `build_repo_profile_context` is in `src/webhook_agent/core/prompts.py:554`:
   ```python
   sections.append(build_repo_profile_context(repo_name))
   ```
   It passes `repo_name` and relies on defaults for everything else. No heuristics are ever passed.
3. **Formal Deletion of Memory Service in PR 4 (PR #382):**
   In PR #382, decision **P5** was finalized and `memory_service.py` was removed via `git rm`. Consequently, the upstream concept of dynamic "memory bank heuristics" no longer has an underlying backend.
4. **Test-Only Exercise:**
   The only place where `memory_bank_heuristics` is ever provided is in `tests/unit/core/test_3tier_prompts.py:74-76`, where a synthetic list of strings is passed to achieve 100% test branch coverage on lines 183–185.

## 3. HOW We Will Decide Its Fate

### Decision Criteria:
1. **Single Source of Truth:** `docs/review_rules.md` already defines the canonical review rules for Hannibal Hub Agents. Dynamic heuristics are not loaded from memory.
2. **Code Truthfulness:** Having a parameter named `memory_bank_heuristics` when the memory subsystem was deleted in PR #382 creates semantic dishonesty.
3. **Signature Cleanliness:** Python functions should accept only parameters that their callers actually supply or intend to configure.

### Recommendation:
**Adopt Option 1.** Remove `memory_bank_heuristics` from `build_repo_profile_context()`:
```python
def build_repo_profile_context(
    repo_name: str,
    primary_stack: str = "Python 3.13, uv, Google ADK, PyGithub, Pub/Sub, Firestore",
) -> str:
    """Build semi-stable Tier 2 repository profile context.

    Remains stable across all PRs targeting the same repository to maximize prefix caching.
    """
    return (
        f"### Repository Profile: {repo_name}\n"
        f"- Primary Stack: {primary_stack}\n"
        f"- Operating Protocols: Zero-Bypass Architecture (all changes via reviewed PR), strictly read-only auditor invariant."
    ).strip()
```
